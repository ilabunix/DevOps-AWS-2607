Yes, with one distinction. The Terraform will provision the Aurora PostgreSQL environment, including the cluster/instances, database, networking, security, and the initial database credentials. We can have those credentials stored securely in Secrets Manager for the appropriate migration process to use.

The application schema, schema owner/roles, tables, indexes, etc. would not automatically be created by the RDS Terraform module. Since we’re migrating from Oracle to PostgreSQL, we’ll first need the Oracle schema converted to PostgreSQL-compatible DDL, and then that schema can be deployed to the new database before the data migration.

Once the target schema is in place and the appropriate source Oracle and target PostgreSQL credentials/connectivity are available, the migration team/tool can perform the actual data movement.
